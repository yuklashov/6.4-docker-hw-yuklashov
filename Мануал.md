Бюджет пользователя — до 50 рублей. Из-за квот использована конфигурация 2 vCPU/8 GiB/20 GiB HDD в существующей default-подсети только для чтения. Созданы только отдельная VM и её SG, загрузочный диск удаляется вместе с VM. Учебный GitLab доступен через SSH-туннель, публикация HTTP в интернет не требовалась.

При первоначальной установке недоступность packages.gitlab.com оставила apt-репозиторий без ключа. На рабочем запуске повреждённый список удалён, bootstrap повторён и пакет установлен. Для диагностики SSH использовалась serial-консоль; реальный доступ к рабочему адресу подтверждён обычным SSH. Настройки VPN не отключались. Подробная локальная история сохранена вне публичного репозитория.

Вспомогательные bootstrap/register-runner скрипты находятся в infra/. Секреты, tfvars, tfstate, планы и рабочие временные каталоги исключены через .gitignore.
