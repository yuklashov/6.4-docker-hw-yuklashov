# GitLab — актуальное условие

Открыто в SYS-62 27 октября 2026 года: https://netology.ru/profile/program/cicd-62/lessons/656572/lesson_items/3523486

Официальная версия: https://github.com/netology-code/sdvps-homeworks/blob/main/8-03.md

1. Развернуть локальный GitLab по Vagrantfile из netology-code/sdvps-materials, создать проект и пустой репозиторий, зарегистрировать и запустить Docker Runner. Приложить снимки настроек раннера.
2. Перенести учебный репозиторий на GitLab, изменив origin. Написать .gitlab-ci.yml, приложить снимки успешных сборок.
3. Дополнительно: сборка стартует без ожидания тестов; тесты запускаются при изменении *.go.

Формат: форк шаблона sys-pattern-homework на GitHub, README с именем и ответами. В текущем кабинете это самопроверка; есть поля ссылки и названия, кнопка отправки решения. Решение ещё не отправлено.
